# MistralBOT
Little ChatBot with Mistral.
I have created AI RAG system using Mistral model. This model reads your document, where you store all the info, learns it and then can answer questions. I also added some weather API and added discord bot, where your bot sees the servers messages, can reply to them and you can write the bot message by @BOT, whaterwer you call your bot and it will answer. Other file is for finance. I have just dipped fingers into this and still think what could i create that would solve problems, but for now this just analizes the payments.
